# Lab 6 - Techniques of Optimization for training

This lab focuses on various optimization techniques used in training machine learning models. The goal is to understand and implement different optimization algorithms to improve the training process and model performance.

1. Bias and Variance Trade-off
   - Understand the concepts of bias and variance in machine learning and why we need to balance them.

2. Hyperparameter Tuning
   - Learn about hyperparameters and their impact on model performance.

3. Strategies to improve Model Performance
   - Strategies depending of Bias or Variance problem.

4. Basic Hyperparameters
   - Learning Rate
   - Number of Epochs
   - Batch Size

5. Advanced Hyperparameters
   - Normalization Techniques (Batch Normalization, Layer Normalization)
   - Initialization Methods (Xavier, He Initialization)
   - Regularization Techniques (L1, L2, Dropout)
   - Optimization Algorithms (SGD, Adam, RMSprop)
